Описание

Высокая производительность · Безопасная работа с памятью · Точные вычисления

Библиотека Nadouf Math полностью написана на Rust и обёрнута для Python, объединяя производительность скомпилированного кода и простоту Python API. Подходит для научных вычислений, анализа данных и обучения.

Возможности

  • Базовые операции: сложение, разность, произведение, деление
  • Степени и корни: квадрат, куб, произвольная степень, квадратный корень, кубический корень
  • Теория чисел: факториал (до 33 включительно), НОД, НОК
  • Тригонометрия: синус, косинус, тангенс (через ряд Тейлора)
  • Продвинутая математика: тетрация, функция знака
  • Объектно-ориентированный API: вычисления с состоянием и цепочками методов

Установка

Из PyPi (рекомендуется)

pip install nadouf-math

Из исходников

git clone https://github.com/CrabNadouf/Nadouf_Math_Library.git cd Nadouf_Math_Library pip install maturin maturin develop

Быстрый старт

from nadouf_math import Nadoufmath, sum_of, dif_of, factorial # Стиль 1: цепочка методов calc = Nadoufmath(5) print(calc.sum_of([5]).dif_of([6]).factorial()) # Стиль 2: пошагово calc = Nadoufmath(5) calc = calc.sum_of([5]) calc = calc.dif_of([6]) calc = calc.factorial() print(calc) # Стиль 3: функции напрямую result = sum_of([5, 5]) result = dif_of([result, 6]) result = factorial(int(result)) print(result)

Объектно-ориентированный API (класс Nadoufmath)

from nadouf_math import Nadoufmath # Однострочная цепочка print(Nadoufmath(7).sum_of([3]).dif_of([5])) # Пошагово calc = Nadoufmath(7) calc = calc.sum_of([3]) calc = calc.dif_of([5]) print(calc) # Многострочная цепочка result = (Nadoufmath(7) .sum_of([3]) .dif_of([5])) print(result)
